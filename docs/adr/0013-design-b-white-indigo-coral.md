# ADR 0013: 案B のデザイン（白地 × 藍 × 珊瑚）

- ステータス: 採用（2026-09-20）
- 置き換えるもの: ADR 0007 の「生成り × 藍 × 柿渋」の配色と、施設ページの構造
- 見本: `docs/design/reference-b/jot-spot-mobile.html`（390px）と `docs/design/reference-b/jot-spot-pc.html`（1280px）

## 決定

### 配色（トークン）

`static/style.css` の `:root` に置く。

| 役割 | 値 |
|---|---|
| 背景 | `#FFFFFF` |
| 本文 | `#101828` |
| 補助文 | `#5A6270` |
| 灰面 | `#F3F5F9` |
| 罫線 | `#E3E6EC` |
| 主色（藍） | `#0F2C59` |
| アクセント（珊瑚・文字とボタンの地） | **`#B84F25`** |
| アクセント（装飾だけ） | `#E8613A` |
| 淡い珊瑚面 | `#FFF1E8` |
| 開 | `#1F7A4D` |
| 不明（面） | `#B9B5A9` / **（文字）`#6E6B63`** |

**見本から 2 か所だけ濃くした。** どちらも計測で基準（通常の文字 4.5:1）に届かなかったため。

- 珊瑚 `#C4562B` → `#B84F25`。白文字を載せると 4.46:1 で、0.04 足りない。淡い珊瑚面の上の文字は 4.03:1
- 不明の文字 `#7A776F` → `#6E6B63`。白地 4.47:1、灰面 4.10:1、バッジの地 3.92:1

見本の `#E8613A` は白文字で 3.39:1 なので、**判子の縁・週の今日の印など装飾にだけ**使う。

**色だけに意味を持たせない。** 判定の丸・判子・ドットには必ず状態の文字（開／休／不明）を添える。

### 構造（施設ページ）

- **ヘッダー**: 藍の帯。スマホはサイト名＋県のチップ＋言語ボタン、1024px 以上でナビを足す
- **言語切替**: 地球アイコン＋現在の言語名＋▾ のボタン 1 つ。`<details>` で開き、**追加の JS を使わない**。
  各言語は自称（日本語 / English / 繁體中文）で並べ、現在の言語に `aria-current` と ✓ を付ける。
  言語が増えても見た目が変わらない
- **ヒーロー帯**: 藍。パンくず・施設名・判定の判子。1024px 以上では週の帯を右に並べる
- **週の帯**: 切符の半券のような 7 マス。スマホでは藍の帯から白いカードを持ち上げる
- **公式のお知らせ**: 淡い珊瑚の面。**基本情報**: 灰面のタイル（PC は 4 列）。**船**: 搭乗券（点線で区切る）
- **2 カラム**（1024px 以上）: 右列（写真・主ボタン・地図）は sticky。スマホでは判定の直後に来て、
  下部に固定バー（一次情報への主導線）が出る。PC では固定バーを消す
- 角丸 14〜16px、影 `0 2px 12px rgba(16,24,40,.10)`

### 持っていない事実は出さない

タイルは値がある項目だけ描く（料金が無い施設に空の料金タイルを出さない）。搭乗券の始発・終発・
所要・運賃も、取れているものだけ並べる。運航日が取れていなければ「運航日 ？」の札を出す（ADR 0004）。

### ダークテーマをやめた

案Bは白地の設計で、トークンが 1 組しかない。暗色の対応表を推測で作ると、計測していない配色が
本番に出る。`color-scheme: light` に固定した。

### フォント: 見送り（実測した）

見本の Zen Kaku Gothic New 900 は参考に留め、**Web フォントは読み込まない**（システムフォントのみ）。
見出しの太さは `font-weight: 800` で出す。

見出しだけ Zen Kaku Gothic New（700/900、`display=swap`、preconnect つき）を読む形を作って、
施設ページの LCP を 3 言語で測った（手元・非圧縮・モバイル既定）。

| | フォントなし | 見出しに Web フォント | 差 |
|---|---|---|---|
| 日本語 | 6,161ms | 7,610ms | **+1.45s** |
| English | 6,069ms | 6,905ms | +0.84s |
| 繁體中文 | 6,209ms | 8,751ms | **+2.54s** |

3 言語とも 0.5 秒以上悪化した（繁体字がいちばん重い）ので入れない。
Zen Kaku Gothic New は日本語のフォントで、繁体字は結局フォールバックに落ちる点も見送りの理由。

### 直したもの（Lighthouse の指摘）

- **週のマスの数字が白いまま**だった。藍の帯の中の白いカードで文字色を戻していなかった
  （白地に白、1.09:1）。`.hero-card` に `color: var(--ink)` を入れた
- **言語ボタンの読み上げ名に、見えている文字（日本語）が入っていなかった**（`aria-label` で
  上書きしていた。WCAG 2.5.3）。`aria-label` をやめ、見えない文字（`.visually-hidden`）で
  役割を添える形にした
- **ヒーローのパンくずのリンクが色でしか見分けられなかった**（白い文字の中の白いリンク）。下線を引いた
- **フッタの一次情報リンクの当たり判定が 18px** だった。上下に余白を足して 24px 以上にした
- **写真の読み込みでクレジットがずれた**（CLS 0.026）。写真に `aspect-ratio: 3 / 2` を入れて
  場所を先に取る（見本も高さの決まった写真枠）。CLS は 3 言語とも 0 になった

### 計測（2026-09-20、手元・非圧縮・モバイル既定）

| ページ | before perf / a11y | after perf / a11y | after LCP |
|---|---|---|---|
| 施設 | 73 / 96 | 70 / 100 | 6,161ms |
| トップ | 65 / 100 | 65 / 100 | 6,913ms |
| エリア | — | 74 / 100 | 4,943ms |
| 交通 | — | 84 / 100 | 3,637ms |

手元の数字は本番と比べられない（圧縮なし、画像が原寸、Kaspersky が 203KB のスクリプトを
差し込む）。**本番の数字は配置後に測り直す。** 施設ページの LCP は写真で、1 枚 500KB の
画像が最大の重り（採用画像の縮小は別の課題）。

## 追記（2026-09-21）: 地図は押したときだけ読み込む

施設ページの地図（ADR 0006 の経路④）は、枠とボタンだけを置き、**押したときに iframe を作る**
（`static/map.js`、依存なしの 25 行）。押すまで Google へ一切通信しない。

そこに至った計測:

| やったこと | 施設ページの様子 |
|---|---|
| 何もしない（地図が画面の上） | LCP 8.1 秒、Google 関連 445KiB が初期表示に乗る |
| 地図をスマホで最後に送る（`loading="lazy"` のまま） | 取得は LCP の後ろへ（1.5 秒以降）。ただし 445KiB の通信は起き、
描画待ちが回によって 1.07 秒付き、perf が 72〜98 で揺れた |
| 押したときだけ読み込む（これ） | 押すまで Google への通信 **0 件** |

`loading="lazy"` は「画面に近づいたら読む」で、Chrome の判定は緩く、スクロールしなくても
最終的には読み込む。**初期表示から外れるだけで、通信そのものは止まらない。**

Static Maps API は使わない（鍵と課金が増える）。JavaScript が動かない環境では枠とボタンだけが残り、
その下の「地図で見る（外部）」から Google マップへ行ける。プライバシーポリシーの地図の段落は
3 言語とも「『地図を開く』を押すまで Google への通信は発生しません」に書き換えた。

## 共通化したいもの（sitemill に置きたい）

akiya-atlas も同じ構造を使うので、後でエンジンに寄せる候補。実装はこのサービスに置いたまま。

1. ヒーロー帯＋2 カラム＋sticky 右列のレイアウト（`.hero` / `.layout` / `.col-side`）
2. 言語ボタン（`<details>` の自称メニュー。`locales` と `meta.alternates` だけで描ける）
3. 判定の判子（`state.*` の文言と状態から描く。色は `--accent` などのトークン）
4. 下部固定バー（スマホだけ出す主導線）

詳細は `docs/design/sitemill-proposals.md`。
