# ADR 0013: 案B のデザイン（白地 × 藍 × 珊瑚）

- ステータス: 採用（2026-09-20）
- 置き換えるもの: ADR 0007 の「生成り × 藍 × 柿渋」の配色と、施設ページの構造
- 見本: `docs/design/reference-b/jot-spot-mobile.html`（390px）と `docs/design/reference-b/jot-spot-pc.html`（1280px）

## 決定

### 配色（トークン）

`static/style.css` の `:root` に置く。

| 役割 | 値 |
|---|---|
| 背景 | `#FFFFFF` |
| 本文 | `#101828` |
| 補助文 | `#5A6270` |
| 灰面 | `#F3F5F9` |
| 罫線 | `#E3E6EC` |
| 主色（藍） | `#0F2C59` |
| アクセント（珊瑚・文字とボタンの地） | **`#B84F25`** |
| アクセント（装飾だけ） | `#E8613A` |
| 淡い珊瑚面 | `#FFF1E8` |
| 開 | `#1F7A4D` |
| 不明（面） | `#B9B5A9` / **（文字）`#6E6B63`** |

**見本から 2 か所だけ濃くした。** どちらも計測で基準（通常の文字 4.5:1）に届かなかったため。

- 珊瑚 `#C4562B` → `#B84F25`。白文字を載せると 4.46:1 で、0.04 足りない。淡い珊瑚面の上の文字は 4.03:1
- 不明の文字 `#7A776F` → `#6E6B63`。白地 4.47:1、灰面 4.10:1、バッジの地 3.92:1

見本の `#E8613A` は白文字で 3.39:1 なので、**判子の縁・週の今日の印など装飾にだけ**使う。

### 全ペアの実測（2026-09-20）

計測は `srgb` 相対輝度から。半透明の色は下地に重ねた実効色で測る。

| 補助文 `#5A6270` / 白 | 6.15:1 | 4.5 |
| 補助文 / 灰面 | 5.63:1 | 4.5 |
| リンク・藍 `#0F2C59` / 白 | 13.77:1 | 4.5 |

**色だけに意味を持たせない。** 判定の丸・判子・ドットには必ず状態の文字（開／休／不明）を添える。

### 構造（施設ページ）

- **ヘッダー**: 藍の帯。スマホはサイト名＋県のチップ＋言語ボタン、1024px 以上でナビを足す
- **言語切替**: 地球アイコン＋現在の言語名＋▾ のボタン 1 つ。`<details>` で開き、**追加の JS を使わない**。
  各言語は自称（日本語 / English / 繁體中文）で並べ、現在の言語に `aria-current` と ✓ を付ける。
  言語が増えても見た目が変わらない
- **ヒーロー帯**: 藍。パンくず・施設名・判定の判子。1024px 以上では週の帯を右に並べる
- **週の帯**: 切符の半券のような 7 マス。スマホでは藍の帯から白いカードを持ち上げる
- **公式のお知らせ**: 淡い珊瑚の面。**基本情報**: 灰面のタイル（PC は 4 列）。**船**: 搭乗券（点線で区切る）
- **2 カラム**（1024px 以上）: 右列（写真・主ボタン・地図）は sticky。スマホでは判定の直後に来て、
  下部に固定バー（一次情報への主導線）が出る。PC では固定バーを消す
- 角丸 14〜16px、影 `0 2px 12px rgba(16,24,40,.10)`

### 持っていない事実は出さない

タイルは値がある項目だけ描く（料金が無い施設に空の料金タイルを出さない）。搭乗券の始発・終発・
所要・運賃も、取れているものだけ並べる。運航日が取れていなければ「運航日 ？」の札を出す（ADR 0004）。

### ダークテーマをやめた

案Bは白地の設計で、トークンが 1 組しかない。暗色の対応表を推測で作ると、計測していない配色が
本番に出る。`color-scheme: light` に固定した。

### フォント

見本の Zen Kaku Gothic New 900 は参考に留め、**Web フォントは読み込まない**（システムフォントのみ）。
見出しの太さは `font-weight: 800` で出す。入れるかどうかは 3 言語の LCP を測ってから決める。

## 共通化したいもの（sitemill に置きたい）

akiya-atlas も同じ構造を使うので、後でエンジンに寄せる候補。実装はこのサービスに置いたまま。

1. ヒーロー帯＋2 カラム＋sticky 右列のレイアウト（`.hero` / `.layout` / `.col-side`）
2. 言語ボタン（`<details>` の自称メニュー。`locales` と `meta.alternates` だけで描ける）
3. 判定の判子（`state.*` の文言と状態から描く。色は `--accent` などのトークン）
4. 下部固定バー（スマホだけ出す主導線）

詳細は `docs/design/sitemill-proposals.md`。
