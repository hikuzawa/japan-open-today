# ADR 0006: 視覚要素と画像ライセンスの 4 経路、収益導線

- ステータス: 採用（2026-09-12）

## 背景
観光サイトは写真で判断されるが、写真は権利の塊である。曖昧なものを載せる誘惑が最も強い領域なので、
判定を自動化して既定を不採用にし、**写真が無くても成立するデザイン**を先に用意する。

## 決定

### 画像の採用経路は 4 つだけ
1. **都道府県・市町・観光協会のフリー素材**: 規約ページを sitemill の `detect_license` で判定し、
   ホワイトリスト（CC BY 2.1JP/3.0/4.0、CC0、政府標準利用規約 2.0、CC BY 互換と明記された自治体オープンデータ）に
   一致した証拠がある場合のみ採用
2. **Wikimedia Commons の CC BY / CC0**: ファイル情報 API からライセンス・作者・ファイル URL を取得し、
   CC BY 系（SA・NC・ND を除く）と CC0 のみ採用。作者名とライセンス名をクレジットに出す
3. **公式 SNS の埋め込み**（YouTube / Instagram / X）: 埋め込み機能経由のみ。転載はしない
4. **Google Maps の埋め込み**: place モード。キーが無いときは外部リンクにフォールバックする

- 上記に当てはまらないもの、ライセンスが読み取れないものは**すべて不採用**。人手で判断しない
- **実在の場所を AI 画像生成で描くことは禁止**。生成画像は説明図・ピクトグラムに限り「自動生成」と明記する
- 図解はコード生成の SVG（sitemill の `charts`）に限る
- 採用した画像は元 URL・ライセンス・取得日・クレジットをデータとして保持し、`/data/` に一覧する
- ビルド時に「登録済みの資産でない `<img>` がページにある」ならビルドを止める（ADR 0008）

### 写真が無い前提のデザイン
写真枠はデータがある施設にだけ出す。空の枠や「写真なし」の板は並べない。
判断に必要な情報（判定・時間・料金・アクセス）は文字と数字と図解で成立させる（ADR 0007 のデザイン基準）。

### 収益導線
- 収益は宿泊・アクティビティのアフィリエイト（Agoda・Booking.com・Klook 等）。利用者から直接課金しない
- **契約が済むまで CTA は「準備中」と表示し、ダミーリンクは置かない**
- 置き場所: エリアページに宿泊、施設ページにアクティビティ・入場券の枠を用意する。
  各 ASP の掲載ルール（「広告」表記など）に合わせた文言をテンプレートに持つ
- 企業との直接契約はしない

## 影響
- 第 1 フェーズは写真が 1 枚も付かない可能性がある。S3 で 4 経路を実際に走らせ、
  香川の対象施設について何件に写真が付いたかを数えて報告する
- ライセンス判定パイプラインは sitemill の共通モジュールとして実装する（akiya-atlas では設計のみだった箇所）

## 追記（2026-09-12）: 実測の結果と、経路ごとの扱いの確定

### 経路② Wikimedia Commons: 主力になった
Commons のカテゴリ名を**リンクを辿って確定**し（推測をやめた）、継承義務の無いライセンスを
受け入れるようにした（sitemill ADR 0005 追記）ところ、12 施設で **41 枚・カバー率 83%** になった
（S3 の 5 枚・23% から）。内訳は CC BY 2.5 が 25、CC BY 4.0 が 5、パブリックドメイン 4、CC0 3、他 4。
写真が付かなかったのは豊島美術館と父母ヶ浜の 2 件で、どちらも候補 6 件すべてが CC BY-SA だった。

カテゴリ名の推測は 13 件中 6 件で誤っていた（`Shikoku Mura` ではなく `Shikokumura`、
`Kotohira-gu` ではなく `Kotohira-gū` など）。**カテゴリ名は推測しない**を原則として固定する。
辿れなかったものは空にして「カテゴリなし」として記録する。

### 経路① 自治体・観光協会の素材: 当面は採用 0 件（事実として記録）
- 香川県（`pref.kagawa.lg.jp`）: 「All Rights Reserved」→ 不採用
- 高松市: 「All Rights Reserved」→ 不採用
- 香川県観光協会（`my-kagawa.jp`）: フッターに「ALL RIGHTS RESERVED」→ 不採用
- 三豊市観光交流局: 「写真の貸し出し」の案内はあるが**申請が必要** → 不採用（人の判断が要るものは自動で回せない）
- 小豆島観光協会: 規約ページに到達できず（`/copyright/`・`/sitepolicy/` は 404）→ 不採用

いずれも「規約が読めたうえでホワイトリスト外」であり、判定が厳しすぎるのではなく素材が公開されていない。
S6 の発見でサイト構造が分かったら、素材ページの有無を再確認する。

### 経路③ 公式 SNS の埋め込み: 保留
12 施設中 11 施設に公式アカウントがあるが、埋め込める単体投稿へのリンクは 0 件で、
Instagram と X は oEmbed の利用登録（人間タスク）が要る。**当面は埋め込まず、施設ページから
公式アカウントへのリンクだけを置く**（`Spot.social`）。登録が済んだら埋め込みに切り替える。

### 経路④ Maps: 鍵の取得待ち
12 施設すべて外部リンクにフォールバック中（設計どおり）。鍵は事業側が取得する。

## 追記（2026-09-14）: 写真の経路は 2（Commons）に寄せる

経路 1（自治体・観光協会のフリー素材）を県内 15 サイトで実測し、**採用 0 件**だった。
測り方と内訳は sitemill ADR 0020 の追記に置いた（他県に広げるときはそちらを見る）。
道具は `tools/probe_municipal_photos.py`、記録は `data/runs/municipal-photo-terms.json`。

到達できたのは 17 市町のうち 13 市町の公式サイト。残る 4 市町（東かがわ市・宇多津町・琴平町・
多度津町）は、**収録済みの情報源からリンクで辿り着けなかった**ので当たっていない。
URL を組み立てれば当たれるが、それはしない（CLAUDE.md の原則）。4 市町を足しても
結論は変わらないと見ている。

写真は経路 2（Wikimedia Commons）で積む。281 施設のうち 71 施設に写真がある（2026-09-14）。
頭打ちは Commons の記事の有無で、香川の小さな施設には記事そのものが無い（163 件）。

経路 3（公式 SNS の埋め込み）は保留のまま。経路 4（地図の埋め込み）は稼働中。
