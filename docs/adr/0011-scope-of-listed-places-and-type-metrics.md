# ADR 0011: 収録する場所の線引きと、型別の充足率

- ステータス: 採用（2026-09-12、事業側の承認済み）

## 背景

香川県観光協会の「スポット・体験」一覧は 570 件（2026-09-12 実測）。ここには見学施設のほかに
うどん店・直売所・体験プログラム・宿が混ざっている。第 1 フェーズの対象は ADR 0001 で
「観光施設と交通」と決めているが、**外す基準が書かれていなかった**。将来「飲食店も入れるか」を
判断するときに、前回どういう理由で外したのかが分からないと同じ議論をやり直すことになる。

あわせて、S6 の実測で分かったことがある。営業時間が取れるかどうかは**施設の規模ではなく、
入場ゲートの有無**で決まる。12 件の内訳:

| 型 | 営業時間 | 例 |
|---|---|---|
| 有料・ゲートのある施設 | 9/9 | 栗林公園、四国村、県立ミュージアム、地中美術館、寒霞渓、映画村 |
| 無料・屋外の場所 | 0/3 | 父母ヶ浜、金刀比羅宮、玉藻公園 |

県の一覧の上位（閲覧数順）43 件は絶景・景勝地 9／映画ロケ地 7／島 4／庭園 4／城跡 4／
海水浴 3 と、**無料・屋外が多い**。全域に広げると「時間の定めが無い場所」が主に増えるので、
全体をひとつの充足率で見ると、対象の広げ方で数字が動くだけになる。

## 決定

### 1. 収録の線引き（第 1 フェーズ）

**収録する**（`spot` として持つ）のは、次のすべてを満たす場所。

1. **訪問先そのもの**である（そこへ行くこと自体が目的になる）
2. **運営主体が判定できる**（ADR 0009 のゲートを通る）
3. **開いているかどうかが日によって変わりうる**か、または変わらないことを一次情報で示せる
4. 公式の一次情報（施設・市町・観光協会・交通事業者）が存在する

**収録しない**もの。理由を型ごとに残す。

| 型 | 外す理由 |
|---|---|
| 飲食店（うどん店・カフェ） | 数が多く（県内のうどん店だけで数百）、休業が不定期で当日変更が SNS のみのことが多い。一次情報の鮮度をこのサービスの基準（毎日巡回・根拠つき）で保てない。**「今日開いているか」の精度が出ない対象を混ぜると、サイト全体の信頼が落ちる** |
| 物販（直売所・土産店・道の駅の物販部分） | 訪問先ではなく立ち寄り先で、開いているかの価値が相対的に低い。道の駅は施設（トイレ・展望・温泉）として一次情報があるものは収録対象に入れる |
| 体験プログラム・ツアー・教室 | 開催日が募集単位で決まり、施設の開館時間とは別の構造（予約枠）を持つ。第 1 フェーズのスキーマ（開館時間＋定休日規則＋告知）では表せない |
| 宿泊施設 | 「開いているか」が問題にならない（通年営業が前提）。宿はアフィリエイトの導線側で扱う（ADR 0006） |
| イベント・期間限定の催事 | 期間そのものが主題で、施設の開閉とは別。第 2 フェーズで「今週のイベント」として扱う余地はある |
| 祭・行事 | 日付が主題。上と同じ |
| 競技・運動の施設（ゴルフ場・体育館・球場・テニスコート） | 予約して使う施設で、旅行者が「今日行けるか」を調べる対象ではない。「運動公園」は公園として訪れる場所なので収録する |
| アウトレット・工場直売 | 物販と同じ |

判断に迷ったものは残す（収録する）。実測で迷ったのは次の型で、いずれも観光協会の一覧に
載っていて営業時間があるため収録した。**再検討するならここから**である。

- 盆栽センター・植木センター（物販でもあるが、見学が目的になる）
- 日本ドルフィンセンター（体験もあるが、施設として見学できる）
- 道の駅（物販が主だが、展望・温泉・トイレのある施設として一次情報がある）
- 市町の文化会館・交流センター（催しが主で、常設の見どころが無いものもある）

**将来この線引きを変えるときの起点**: 飲食店を入れる判断は、「当日の営業を公式の一次情報から
根拠つきで取れるか」が変わったとき（例: 店が公式サイトで営業カレンダーを出す、自治体が
営業状況の公開データを持つ）に限る。SNS の投稿を根拠にする形は取らない（ADR 0006 で経路③を
保留したのと同じ理由）。

### 2. 場所の型を宣言する（`spot_type`）

`data/sources/*.yaml` の各 `spot` に `spot_type` を持たせる。既定は書かない（`unknown`）。

- `gated`: 入場料・入場ゲート・開館時間があり、閉まっている時間が存在する施設
- `open_air`: 無料で、門や柵で閉じられない屋外の場所（砂浜・展望・境内・遊歩道）
- `unknown`: どちらとも判定できていない。**推測で埋めない**（充足率では別に数える）

判定は一次情報の記述で行う（入園料・開館時間の記載があれば `gated`、「入園自由」「常時開放」
「24時間」や、料金・時間の記載が無く柵の無い屋外であることが分かれば `open_air`）。

### 3. 充足率は型別に見る

全体の 1 つの数字は指標にしない。次の 2 つを別に計測する（`tools/report_coverage.py`）。

- **ゲートのある施設の営業時間充足率** — こちらが「取れているか」の指標
- **屋外の場所の判定確定率** — 「時間の定めが無い」と明示できている割合。
  こちらは営業時間ではなく、**利用者が行動を決められる状態にあるか**を見る

`unknown` 型の件数も併記し、増えたら型の判定側を直す（レビュー行列と同じ考え方）。

## 影響

- 570 件のうち第 1 フェーズの対象は 150〜250 件と見込む。実数は発見を走らせて確定する
- 拡張は ①ゲートのある施設 → ②島と主要観光地の屋外 → ③残り の順に行い、①の時点で報告する
- `spot_type` が `open_air` で営業時間が取れない場所は、「不明」ではなく
  「時間の定めは公式ページに記載がありません」と明示して周辺情報を出す（ADR 0003 追記）

## 追記（2026-09-13、③ 数え上げの完了と 285 件の見直し）

### 数え上げは完了した（567 件）

一覧の検索は 1 ページ 20 件で、**サイト自身が出すページ送りのリンクは 404 を返す**
（絞り込みの条件が `area_l[0]` の形に書き換わる）。検索が通っているパスに `page:N` を足すと
辿れることを確かめ、エリア × 大分類のすべての組み合わせで「N 件ありました」の数まで
取り切った。取りきれない組み合わせは 0 件になった。

### 分類は提案、名前が決める

観光協会の分類（大分類・小分類）は**そこで何ができるか**で付いていて、施設の素性とは別のことが
ある。分類だけで除外していたため、次のものがまとめて対象外になっていた（285 件の見直しで判明）。

- 「体験」に分類された美術館・博物館・記念館（讃岐漆芸美術館・天体望遠鏡博物館・平賀源内記念館）
- 「キャンプ場」に分類された公園（さぬき空港公園・県立亀鶴公園・国営讃岐まんのう公園）
- 「グルメ」に分類された灯台と交流施設（せとしるべ・やしまーる）
- 「物産・土産」に分類された道の駅

そこで判定の順序を次のようにした。

1. 名前の頭の【…体験】【…ツアー】は催し物（**【施設見学】【産業学習】は含めない**。
   観光協会は博物館の見学もこの形で載せていて、除くとマルキン醤油記念館が消える）
2. 名前に対象外の語があるか。施設の語（美術館・公園・灯台・道の駅…）も両方あるときは、
   **どちらがその場所の素性か**で決める
   - 施設の語が頭にある → 施設（「道の駅「たからだの里さいた」（物産館）」）
   - 区切り記号で場所を並べている → 施設（「一の宮公園・一の宮海岸海水浴場・キャンプ場」）
   - どちらでもない → 末尾の語が素性（「奥の湯公園キャンプ場」は キャンプ場）
   - 対象外の語が頭にある → 対象外（「物産市「道の駅・ことひき」」は道の駅の中の売店）
3. 名前で決まらなければ、分類の見出しで決める

### 一覧に混ざっている「場所ではないもの」

数え上げの一覧には、施設以外のものが項目として入っている。次の型を対象外に足した。

- **作品 1 点**（`artwork`）: 「「鬼屏風」／流政之作（瀬戸大橋記念公園）」。美術館・公園の中の
  彫刻で、それ自体に開館時間は無い。**7 件が公開されていた**ので取り下げた
- **会期のある展示**（`event`）: 「香川県立ミュージアム常設展「…」」「共催展「第27回…」」
- **運営会社**（`company`）: 「株式会社まんでがん」
- **運動施設**（`sports`）: 市民プール・カントリー倶楽部・B&G 海洋センター・スポーツランド。
  「運動公園」は公園として訪れる場所なので除かない（この線引きは変えていない）
- **高速道路の休憩施設**（`highway`）: パーキングエリア・サービスエリア。高速に乗っている人しか
  寄れないので行き先にならない。**道の駅は対象に含める**（市町・第三セクターの観光施設で、
  展望・温泉・物産があり、営業時間が公式に出ている）
- **釣り**（`experience`）: 「安戸池釣場」「内場川釣り」。場所ではなく活動である

収録済みのものにも同じ規則を当てる道具を作った（`tools/prune_spots.py`）。規則を直したときに、
すでに情報源に書いてしまったものを外し、理由を `data/runs/pruned-spots.json` に残す。

### 結果

| | 見直し前 | 見直し後 |
|---|---|---|
| 数え上げ | 462 / 570（取りきれず 108） | **567 / 567** |
| ゲートのある施設 | 89 | 154（収録） |
| 屋外の場所 | 86 | 127（収録） |
| 対象外 | 285 | 280 |
| 型が未判定 | 2 | 3 |

型が未判定の 3 件（新屋島水族館・中寺廃寺跡・杉王神社）は、観光協会のページの基本情報の表が
**空**で、住所も時間も載っていない。一覧を情報源にする限りは決められないので、
「決められない」と記録して残す（推測で型を付けない）。
